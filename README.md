# ListingPro AI - EC出品自動化ソリューション LP

## プロジェクト概要
EC事業者向けの出品自動化ツール「ListingPro AI」のランディングページ（LP）。
AIを活用した画像加工、採寸、データ入力などの機能を訴求し、業務効率化とコスト削減をアピールします。

## 主な機能・セクション
1.  **ヒーローセクション**: キャッチコピー、CTAボタン、導入実績
2.  **実績・効果**: 導入企業数、削減時間などの数値的アピール
3.  **役割別メリット**: ささげ担当、経理、事業責任者ごとのメリット提示
4.  **サービスの特徴**: 機能一覧（モバイルアプリ、ダッシュボード、リネームなど） ※カードグリッドデザインに刷新
5.  **詳細機能紹介**:
    *   AI白抜き加工
    *   自動採寸
    *   一括画像加工（リサイズ・ロゴ挿入）
    *   スマートリネーム
    *   着用画像生成（AIモデル）
6.  **コストパフォーマンス**: 従来コストとの比較チャート
7.  **料金プラン**: 年間/月次プランの切り替えテーブル
8.  **FAQ**: よくある質問（アコーディオン形式）
9.  **フッター**: リンク集、コピーライト

## 技術スタック
*   **HTML5**: セマンティックなマークアップ
*   **Tailwind CSS**: ユーティリティファーストなスタイリング
*   **JavaScript**:
    *   Chart.js: コスト比較グラフの描画
    *   インタラクション: FAQアコーディオン、料金プラン切り替え
*   **Font Awesome**: アイコンフォント
*   **Google Fonts**: Noto Sans JP（日本語フォント）

## デザインの特徴
*   **カラーパレット**: 信頼感のあるブルー（`#2563eb`）を基調とし、アクセントにグラデーションを使用。
*   **レスポンシブ対応**: モバイルからデスクトップまで最適化されたレイアウト。
*   **インタラクション**: ホバーエフェクト、スムーススクロール、タブ切り替えなど。
