## 🚀 デプロイ手順（5ステップ）

### ステップ1: メールアカウント作成（最重要！）

**Xserverサーバーパネルで以下を設定:**

1. **メールアカウント作成**
   - サーバーパネル → メールアカウント設定
   - ドメイン: `relight-rl.com`
   - メールアドレス: `info`
   - 完全なアドレス: `info@relight-rl.com`

2. **メール転送設定**
   - サーバーパネル → メール転送設定
   - 転送元: `info@relight-rl.com`
   - 転送先: `kenji.noto@relight-rl.com`

**重要**: この設定がないとメール送信できません！

---

### ステップ2: SPF/DKIM設定（迷惑メール対策）

#### SPFレコード
サーバーパネル → DNSレコード設定 → DNSレコード追加

| 種別 | ホスト名 | 内容 |
|------|----------|------|
| TXT  | @        | `v=spf1 include:_spf.xserver.jp ~all` |

#### DKIM設定
サーバーパネル → DKIM設定 → 有効化

**反映時間**: 最大24時間

---

### ステップ3: ファイルアップロード

#### 方法A: FileZilla（推奨）

**接続情報:**
```
ホスト: sv16714.xserver.jp
ユーザー名: xs319839
パスワード: あなたのFTPパスワード
ポート: 21
```

**アップロード先:**
```
/public_html/relight-rl.com/
```

**アップロードファイル:**
```
✅ index.html
✅ contact.html
✅ send-email.php
✅ images/ フォルダ（全画像）
```

#### 方法B: Xserver ファイルマネージャー

1. サーバーパネル → ファイルマネージャー
2. ログイン
3. `public_html/relight-rl.com/` に移動
4. アップロードボタンでファイルを選択

---

FileZillaで右クリック → ファイルのパーミッション

## 🔧 トラブルシューティング

### メールが届かない
1. `info@relight-rl.com` のメールアカウントが作成されているか確認
2. メール転送設定が正しいか確認
3. SPF/DKIM設定を確認
4. 迷惑メールフォルダを確認

### 500エラー
1. PHPバージョンを確認（PHP 7.4以上推奨）
2. `send-email.php` のパーミッションを確認
3. サーバーパネル → エラーログを確認

### 画像が表示されない
1. `images/` フォルダがアップロードされているか確認
2. ファイル名が正しいか確認（大文字小文字区別）
